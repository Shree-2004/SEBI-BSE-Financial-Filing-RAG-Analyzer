Ingestion: pdfplumber (table-aware text extraction), pytesseract (OCR fallback for scanned pages)
Embeddings: BAAI/bge-base-en-v1.5
Vector store: Qdrant (or FAISS for local dev)
Hybrid retrieval: dense (embeddings) + BM25 (keyword, for exact numbers/company terms)
Reranking: CrossEncoder
Generation: any LLM API (OpenAI/Claude/local)
Verification: post-generation check that cited claims actually appear in the retrieved source chunk
Backend: FastAPI
Frontend: React (or Streamlit for faster MVP)
Deployment: Railway (backend) + Vercel (frontend)
